# Evaluated Ideas
- Make a food tinder, where the bio has recipes and you can save recipes by swiping
    - Useful for anybody learning to cook
    - Entertaining for those who love cooking or want to learn
    - Would likely be used by us if the app is made well
    - Can teach the user how to cook
    - Liked food can be saved for later use (Ex: Shopping)
- Make a weather app that will show current weather and forecast for next few days
    - Useful to prepare for the day
    - Not entertaining
    - Plenty of other sources of this information
- Make an app for drawing references, where the user can choose what type of images show and whether there is a timer
    - Useful for artists
    - Entertaining for artists or those learning to draw
    - Small userbase in relation to the other ideas
    - Helps the user practice art
